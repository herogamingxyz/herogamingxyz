Continuity

Continuity is a visual enhancement mod for Minecraft that adds connected textures and seamless glass without changing the vanilla gameplay. Glass blocks, bookshelves, sandstone, ores and many other blocks blend together naturally, creating a cleaner and more immersive world. The mod works with Fabric and is designed to be lightweight while significantly improving Minecraft's visuals. It is fully compatible with Sodium and supports resource packs that use the Connected Textures (CTM) format. Whether you are building modern houses, castles or large cities, Continuity makes every structure look smoother, more polished and professional without affecting game performance.

Installation Guide

1. Install the Fabric Loader for your Minecraft version. 2. Install the Fabric API. 3. Download the Continuity mod. 4. Move the Continuity .jar file into the Minecraft mods folder. 5. Install Indium if you are using Sodium for full compatibility. 6. Launch Minecraft and enable a resource pack that supports Connected Textures (CTM) to enjoy seamless block textures.
