Fresh Animations

Fresh Animations is one of the most popular Minecraft resource packs that brings smoother, more realistic and lively animations to mobs while keeping Minecraft's original style. Villagers, Zombies, Creepers, Endermen and many other mobs receive improved animations for a more immersive gameplay experience.

Installation Guide

1. Install OptiFine or Entity Model Features (EMF) with Entity Texture Features (ETF). 2. Download the Fresh Animations resource pack. 3. Move the ZIP file to the resourcepacks folder. 4. Launch Minecraft. 5. Enable Fresh Animations from the Resource Packs menu. 6. Enjoy enhanced mob animations.
