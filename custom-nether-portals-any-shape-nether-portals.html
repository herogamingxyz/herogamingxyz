Custom Nether Portals (Any Shape Nether Portals)

Custom Nether Portals is an amazing Minecraft mod that removes the traditional limitation of rectangular Nether portals. With this mod, players can create Nether portals in any shape, size, or design they want. Whether you want a giant circular portal, a fantasy-style gateway, or a creative decorative structure in your world, this mod makes it possible. It is perfect for builders and creative players who want to enhance their world with unique and visually stunning Nether travel systems. Now Nether portals are not just functional — they are also beautiful and customizable. ✨ Features 🔷 Build Nether portals in any shape 🔷 Fully custom size support 🔷 Survival & Creative mode compatible 🔷 Perfect for builders and map makers 🔷 Enhances world decoration 🔷 Unique Nether travel experience 🔷 Easy to install and use

Installation Guide

●For Minecraft Java Edition Install Minecraft Forge or NeoForge ●Download the mod file Move the .jar file into the mods folder ●Launch Minecraft using Forge/NeoForge profile Start the game ●Enjoy custom-shaped Nether portals
